# Writing playbook

Patterns for case study writing. Terse, actionable, repeatable. Load alongside PORTFOLIO-RUBRIC.md (binary rules) and HUMANIZE.md (prose style).

Counter `[N]` starts at 0, increments when the pattern proves out during a session. Never decremented — edit or remove instead.

## Patterns

- [0] **stage-setting preamble** — Open complex case studies with: anchor sentence ("X is a Y for Z"), three short dimension sentences (workflow/system surfaces), before-state, engagement closer. Use only when 3+ parties, 4+ stack components, or multi-year scope. Worked example: BLINK Scope section.

## Backlog

Patterns to document when they next surface in a rewrite:

- judgment-call structure ("X looks like the hard part. The actual hard part is Y.")
- decomposed-numbers pattern ($600K + $600K + $600K = $2M+)
- "X, not Y" inversion and its dosage rule (one per piece, max)
- structural-insight closer
